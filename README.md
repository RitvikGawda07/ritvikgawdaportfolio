# Ritvik Gawda — Portfolio

A responsive single-page portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Run locally

Open `index.html` in a browser, or run `python3 -m http.server 8000` from this directory and visit `http://localhost:8000`.

## Font and color

The supplied Neue Montreal font archive is installed in `assets/fonts/`. The site uses its thin, book, medium, bold, italic, and semibold italic styles. The palette is the nine-tone grey theme specified for this portfolio, from Bright Snow to Carbon Black.

Content is based on `files/Ritvik Gawda_CV.docx`. Update `index.html` as projects progress.
